# chebu-tutor

Навык начинает учебную сессию в клоне `chebupelka-jev` в режиме тьютора, который ученик назвал флагом. Своих правил тьютора у навыка нет. Сессию ведут `AGENTS.md`, `coding-agent-developement/tutor-modes.md` и протокол `.handoff/README.md`. Навык добавляет к ним проверку флага.

Если ты читаешь этот текст, ученик вызвал навык. Рантайм может передать тебе текст навыка вместо сообщения вызова, и это всё равно вызов.

Флаг `--execute`, `--guide`, `--walkthrough`, `--sandbox` или `--quiz` выбирает режим с тем же id. Слова после флага остаются словами ученика: цель, тикет, ограничения. Флаг не даёт разрешений: их по-прежнему задаёт раздел «Границы» `AGENTS.md`.

```text
использование: chebu-tutor --execute|--guide|--walkthrough|--sandbox|--quiz [цель, тикет, ограничения]
```

## Порядок

1. Найди корень Git текущей папки. Если в нём нет `AGENTS.md` и `.handoff/handoff.py`, ответь `навык chebu-tutor работает только в клоне chebupelka-jev` и остановись.
2. Выполни из корня команду проверки инструментом shell. Она заменяет шаг 1 раздела «Начни сессию» `AGENTS.md`: команду `start` без ключа `--mode` не выполняй. Вместо `<id>` подставь id своего рантайма: `claude`, `codex`, `cursor`, `devin`, `grok` или `opencode`.
3. Если команда завершилась кодом 2 и последняя строка stderr начинается с `использование: chebu-tutor`, это отказ. Если причина называет неподставленный плейсхолдер, замени строку между разделителями словами из сообщения вызова и повтори шаг 2. В остальных случаях покажи ученику stderr и остановись: снимок не читай, файлы не меняй. Если код 2 сообщает о рантайме, возьми id из списка в сообщении и повтори шаг 2.
4. Если сессия в этом разговоре уже начата, режим меняет только флаг, а вызов без флага режим не меняет. Строка `Режим тьютора:` из вывода сравнивает флаг со снимком, а не с текущим режимом разговора. Поэтому подтверди смену своей строкой `Режим тьютора: <новый id> по флагу, был <текущий id>` и продолжай по правилам нового режима. Шаги 5–7 пропусти.
5. Продолжи начало сессии по разделу «Начни сессию» `AGENTS.md` с шага 2. Строка `Режим тьютора:` из вывода задаёт режим, потому что флаг важнее снимка. Назови её ученику. Если флага не было, вывод начинается строкой использования, а режим берётся из снимка.
6. Прочитай раздел своего режима в `coding-agent-developement/tutor-modes.md`.
7. Жди, пока ученик назовёт задачу и согласует план. До этого файлы проекта не меняй.
8. Работай по правилам режима.
9. По фразе «закрой сессию» закрой сессию по `AGENTS.md`. В снимок попадает режим, действующий на момент закрытия.

## Команда проверки

```bash
python3 .handoff/handoff.py start --runtime <id> --mode <<'CHEBU_TUTOR_ARGS'
$ARGUMENTS
CHEBU_TUTOR_ARGS
```

Строка между разделителями содержит слова, с которыми ученик вызвал навык. Скопируй её без изменений. Если рантайм не подставил слова и в строке осталось имя плейсхолдера со знаком доллара, замени строку словами из сообщения, которым ученик вызвал навык.

Разделитель `CHEBU_TUTOR_ARGS` стоит в одинарных кавычках, поэтому shell не выполняет `$`, обратные кавычки и кавычки из текста ученика. Не передавай текст ученика аргументами команды и не убирай кавычки вокруг разделителя.
