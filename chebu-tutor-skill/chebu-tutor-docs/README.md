# Пакет chebu-tutor-docs

Пакет описывает навык `chebu-tutor` и порядок его разработки. Навык будет вести учебную сессию `chebupelka-jev` в режиме, который ученик задаёт флагом: `/chebu-tutor --execute`, `--guide`, `--walkthrough`, `--sandbox` или `--quiz`. Поведение одинаково в шести рантаймах репозитория: Claude Code, Codex, Cursor, Devin, Grok Build и OpenCode.

Навык пока не реализован. Пакет содержит контракт, архитектуру, правила версий, факты о рантаймах и семь этапов разработки. Каждый этап исполняет одна сессия Claude Code.

## Начать сессию разработки

1. Открой [progress.md](progress.md) и найди первый этап со статусом «К выполнению».
2. Открой Claude Code в корне основного клона и отправь промпт из [development-workflow.md](development-workflow.md), подставив номер и файл этапа.
3. Агент начнёт сессию по AGENTS.md, прочитает этот индекс, прогресс и файл этапа и согласует с тобой план.

Этап 0 означает сам пакет документации. Его статус ведёт [progress.md](progress.md), а «Готово» ставит первая сессия этапа 1 после слияния PR пакета.

Каждый файл этапа содержит одни и те же разделы в одном порядке: цель, входные условия, что прочитать, шаги, критерий готовности, что записать, границы.
