# Этап 4. Генератор и проверка синхронизации

## Цель

Написать `chebu-tutor-skill/tools/sync.py`. Скрипт строит адаптеры по путям из блоков `skill` шести рантаймов: по фактам [runtime-adapters.md](../runtime-adapters.md) это `.claude/skills/chebu-tutor/SKILL.md` и `.agents/skills/chebu-tutor/SKILL.md`. Второй путь проходит через символическую ссылку `.agents/skills/chebu-tutor` на папку первого (D-12). Источниками служат канонический текст, `skill.json`, блоки `skill` в `runtime-config/` и перечисление режимов. Ключ `--check` сравнивает построенное с файлами на диске и падает при любом расхождении. На этом этапе генератор работает только на временных копиях в тестах. В настоящее дерево адаптеры записывает этап 5.

## Входные условия

| Условие | Команда | Ожидаемый результат |
|---|---|---|
| Этап 3 готов | Строка этапа 3 в [progress.md](../progress.md) | Статус «Готово» |
| Пробы подтверждены | Разделы рантаймов в [runtime-adapters.md](../runtime-adapters.md) | Для каждого рантайма есть проба этапа 1 с итогом или принятое владельцем исключение |

## Шаги

1. Выбери состав полей блока `skill` по фактам runtime-adapters.md. Запиши состав в раздел «Структуры данных» architecture.md.
2. Добавь блок `skill` в каждый файл `runtime-config/runtimes/<id>.json`. Запусти тесты `.handoff`: 63 теста должны пройти, потому что `load_runtime` пропускает новый ключ.
3. Напиши тесты до кода по строкам этапа 4 в verification.md. Каждый тест копирует нужные файлы во временную папку и запускает генератор там.
4. Запусти тесты. Новые тесты должны упасть: генератора нет.
5. Напиши `sync.py`, только стандартная библиотека. Без ключа скрипт записывает адаптеры по путям из блоков `skill`. С ключом `--check` он строит адаптеры в памяти, печатает каждый файл с расхождением и выходит с кодом 1. Каждый адаптер получает метку версии и пометку, что файл сгенерирован из `source/SKILL.md` и вручную не правится.
6. Проверь общие каталоги: если блоки нескольких рантаймов указывают один путь, адаптер пишется один раз, а id рантайма агент подставляет сам. Путь Codex генератор не пишет файлом: он создаёт ссылку `.agents/skills/chebu-tutor` на `../../.claude/skills/chebu-tutor`. `--check` падает, если на этом месте обычная папка или ссылка ведёт в другое место (D-12).
7. Запусти тесты до зелёного итога. Внеси дефект: генератор пропускает метку версии. Тест дрейфа версии должен упасть. Процитируй сообщение и верни код.

## Критерий готовности

- Тесты навыка завершаются `OK`. Каждая строка этапа 4 в verification.md покрыта тестом.
- Тесты `.handoff` завершаются `OK`, 63 теста.
- Дефект метки версии дал падение, сообщение процитировано.
- `git status --short` не показывает адаптеров в каталогах рантаймов: генератор не запускался на настоящем дереве.

## Границы

- `sync.py` не запускается без временной папки. Адаптеры в настоящем дереве появляются на этапе 5.
- Канонический текст меняется только для исправления подстановок.
- Версия остаётся `0.1.0`.
- Коммит, push и PR только по разрешению владельца в текущей сессии.
