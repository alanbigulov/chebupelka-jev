# Этап 7. Выпуск chebu-tutor-v0.1.0

## Цель

Выпустить первую версию навыка по чек-листу [versioning.md](../versioning.md): коммит выпуска, аннотированный тег `chebu-tutor-v0.1.0`, записи в обоих CHANGELOG и ссылка из VERSIONING.md на правила версий навыка.

## Входные условия

| Условие | Команда | Ожидаемый результат |
|---|---|---|
| Этап 6 готов | Строка этапа 6 в [progress.md](../progress.md) | Статус «Готово» |
| HEAD совпадает с `origin/main` | `git fetch origin`, затем `git rev-parse HEAD origin/main` | Два одинаковых SHA |
| Рабочее дерево чистое | `git status --short` | Пустой вывод |
| Тега ещё нет | `git tag --list 'chebu-tutor-v*'` | Пустой вывод |
| Владелец разрешил выпуск | Вопрос владельцу | Разрешены коммит, тег и push тега |

## Прочитать

- [versioning.md](../versioning.md) целиком.
- [VERSIONING.md](../../../VERSIONING.md), раздел «Команды выпуска»: порядок проверки тега у `chebu`.
- [verification.md](../verification.md), журнал приёмки.

## Шаги

1. Выполни чек-лист выпуска из versioning.md по порядку. Версия первого выпуска: `0.1.0`.
2. Перенеси записи `[Unreleased]` CHANGELOG навыка в раздел `[0.1.0], ГГГГ-ММ-ДД`. Перечисли рантаймы с итогом приёмки.
3. Добавь строку о выпуске навыка в `[Unreleased]` [CHANGELOG.md](../../../CHANGELOG.md) проекта.
4. Добавь в VERSIONING.md короткий раздел «Версия навыка chebu-tutor» со ссылкой на versioning.md.
5. Обнови `chebu-tutor-skill/README.md`: навык выпущен, версия 0.1.0.
6. Создай коммит выпуска, аннотированный тег на нём и отправь ветку и тег по разрешению владельца.
7. Сверь тег локально и удалённо командами из versioning.md.

## Критерий готовности

- `git rev-parse chebu-tutor-v0.1.0^{commit}` равен коммиту выпуска.
- `git ls-remote --tags origin chebu-tutor-v0.1.0` печатает тег.
- В коммите выпуска `python3 chebu-tutor-skill/tools/sync.py --check` завершается кодом 0, тесты навыка и `.handoff` завершаются `OK`.
- Метка версии каждого адаптера равна `0.1.0`.

## Что записать

- Строку этапа 7 в [progress.md](../progress.md) со ссылкой на тег.
- Раздел `[0.1.0]` в CHANGELOG навыка и строку в CHANGELOG проекта.

## Границы

- Тег `chebu` `vX.Y.Z` не создаётся: выпуск навыка независим.
- Версия `chebu` в `agent/pyproject.toml` не меняется.
- Тег не переносится и не удаляется без отдельного решения владельца.
