# chebu-tutor-skill

Каталог для разработки навыка `chebu-tutor`: его кода, скриптов и документации. Навык ведёт учебную сессию в режиме, который ученик задаёт флагом команды. Одинаковое поведение в шести рантаймах репозитория проверит приёмка этапа 6.

## Статус

Этап 5: навык установлен, но не выпущен. Генератор [tools/sync.py](tools/sync.py) записал адаптеры в `.claude/skills/chebu-tutor/` и ссылку `.agents/skills/chebu-tutor`. Ученик вызывает навык командой `/chebu-tutor --<режим>`, в Codex `$chebu-tutor --<режим>`, как описывает [tutor-modes.md](../coding-agent-developement/tutor-modes.md#начать-сессию-командой-chebu-tutor). Вызов проверен одним запуском в Claude Code. Приёмку в шести рантаймах проводит этап 6, выпуск `chebu-tutor-v0.1.0` делает этап 7. Версия в [skill.json](skill.json) равна `0.1.0`, тега нет. Флаг проверяет ключ `--mode` у `python3 .handoff/handoff.py start`. Статус этапов ведёт [progress.md](chebu-tutor-docs/progress.md).

## Генератор

Из корня репозитория:

```bash
python3 chebu-tutor-skill/tools/sync.py --check
```

Команда ничего не пишет. Код 0 означает, что адаптеры совпадают с источниками. Код 1 означает расхождение: строки `ошибка:` называют каждый путь. Без ключа генератор записывает адаптеры по блокам `skill` из `runtime-config/runtimes/`. Адаптеры вручную не правят. После правки `source/`, `skill.json` или блока `skill` запусти генератор без ключа и закоммить адаптеры вместе с источником.

## Тесты

Из корня репозитория:

```bash
python3 -m unittest discover -s chebu-tutor-skill/tests -v
```

Тестам нужны стандартная библиотека Python, `git` и `sh`. Тест содержания запускает `python3 .handoff/handoff.py start` в этом клоне, но состояние `.handoff/` не меняет. Сеть и API тесты не используют.

## Состав каталога

| Путь | Назначение | Этап |
|---|---|---|
| `chebu-tutor-docs/` | Документация и поэтапные инструкции разработки | Есть |
| `skill.json` | Имя, версия и требования навыка | Есть, этап 2 |
| `CHANGELOG.md` | История версий навыка | Есть, этап 2 |
| `tests/` | Тесты навыка | Есть с этапа 2, дополнены на этапах 3–4 |
| `source/SKILL.md` | Канонический текст навыка | Есть, этап 3 |
| `source/agents/openai.yaml` | Запрет вызова моделью для Codex | Есть, этап 4 |
| `tools/sync.py` | Генератор адаптеров и проверка синхронизации | Есть, этап 4 |

Адаптеры лежат вне этого каталога: папка `.claude/skills/chebu-tutor/` и ссылка на неё `.agents/skills/chebu-tutor`. Их читают рантаймы, а пишет только `tools/sync.py`. Почему так, объясняет [architecture.md](chebu-tutor-docs/architecture.md).
