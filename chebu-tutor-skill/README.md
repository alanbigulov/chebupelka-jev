# chebu-tutor

Одна команда начинает учебную сессию `chebupelka-jev` в режиме тьютора, который ты выбрал.

```text
/chebu-tutor --guide тикет EDU-02, код пишу сам
```

Версия `0.1.1`, тег [`chebu-tutor-v0.1.1`](https://github.com/alanbigulov/chebupelka-jev/tree/chebu-tutor-v0.1.1). Навык работает в Claude Code, Codex, Cursor, Devin, Grok Build и OpenCode. Это основной способ начать учебную сессию. Промпт «Начни учебную сессию» остаётся запасным путём, когда навык недоступен.

## Возможности

- **Режим одним флагом.** Флаг `--execute`, `--guide`, `--walkthrough`, `--sandbox` или `--quiz` решает, кто меняет код тикета и как ведёт себя агент.
- **Цель в той же строке.** Слова после флага агент читает как твою цель, тикет и ограничения.
- **Продолжение с того же места.** Агент читает снимок `.handoff/SESSION.md`, сверяет его с Git и продолжает записанный шаг. Флаг важнее режима из снимка.
- **Одинаково в шести рантаймах.** Приёмка прошла 54 проверки из 54: девять случаев в каждом рантайме. Каждый запуск записан в [журнале приёмки](chebu-tutor-docs/verification.md#журнал-приёмки).
- **Опечатку в флаге ловит код.** Флаг проверяет `handoff.py start --mode` до того, как агент прочитает снимок. Сессия с неверным флагом не начнётся.
- **Ничего не нужно устанавливать.** Навык лежит в клоне: папка `.claude/skills/chebu-tutor/` и ссылка на неё `.agents/skills/chebu-tutor`.

> [!IMPORTANT]
> Флаг не даёт разрешений. Платный запуск `chebu` с ключом DeepSeek, коммит, push, PR и изменения в трекере агент делает, только если ты разрешил их словами в текущей сессии.

## Перед началом

Тебе нужны:

- Клон `chebupelka-jev` на ветке `main` или на ветке от тега `chebu-tutor-v0.1.0` и новее.
- `python3`: навык запускает `.handoff/handoff.py` из клона.
- Один из шести рантаймов, установленный и с выполненным входом: `claude`, `codex`, `cursor-agent`, `devin`, `grok` или `opencode`.

> [!WARNING]
> В теге v0.1.4 и в ветке от него навыка нет. Там нет и ключа `--mode` у `handoff.py`. Сейчас все тикеты начинаются с `main`, и навык в нём есть. Если тикет нужно начать от тега, бери последний тег навыка, сейчас `chebu-tutor-v0.1.1`: код `agent/` в нём совпадает с v0.1.4. Например, `git switch -c edu-06 chebu-tutor-v0.1.1`. В ветке без навыка начни сессию промптом, как описывает раздел [Без навыка](#без-навыка-промпт).

## Первая сессия за пять шагов

Сделаем первую сессию в режиме разбора кода: агент объясняет, файлы проекта не меняются.

1. Открой терминал в корне клона:

   ```bash
   cd chebupelka-jev
   ```

2. Запусти рантайм, например Claude Code:

   ```bash
   claude
   ```

3. Набери первым сообщением:

   ```text
   /chebu-tutor --walkthrough разберём run_bash() в agent/chebu.py
   ```

4. Прочитай ответ. Агент начинает со строки режима. В свежем клоне снимка нет, поэтому строка такая:

   ```text
   Режим тьютора: walkthrough по флагу, в снимке режима нет
   ```

   Дальше агент называет состояние репозитория, расхождения со снимком и одно следующее действие. До твоего согласия файлы проекта не меняются.

5. Ответь «план подходит» или поправь план. Чтобы остановиться, напиши «закрой сессию». Агент сохранит снимок, и следующая сессия продолжит с того же места.

## Команда и флаги

```text
/chebu-tutor --<режим> [цель, тикет, ограничения]
```

| Флаг | Кто меняет код тикета | Куда пишет агент | Когда выбрать |
|---|---|---|---|
| `--execute` | Агент, по согласованному плану | Файлы проекта и `.handoff/` | Увидеть весь путь тикета от плана до проверки |
| `--guide` | Ты | Только `.handoff/` | Написать решение своими руками |
| `--walkthrough` | Никто | Только `.handoff/` | Понять код до того, как его менять |
| `--sandbox` | Никто | `.sandbox/` и `.handoff/` | Проверить догадку «а что будет, если» |
| `--quiz` | Никто | Только `.handoff/` | Проверить, что понял пройденное |

Правила каждого режима описывает [tutor-modes.md](../coding-agent-developement/tutor-modes.md).

- Флаг в команде один. Два флага или флаг вне списка агент отклонит, и работа не начнётся.
- Флагом считается любое слово, которое начинается с `--`, даже внутри цели.
- Без флага навык печатает строку использования и берёт режим из снимка. Если режима в снимке нет, агент покажет таблицу режимов и спросит один раз.
- В уже начатой сессии флаг меняет режим, а вызов без флага режим не меняет.

## Вызов в каждом рантайме

Запускай рантайм в корне клона. Флаги и текст после них одинаковы везде.

| Рантайм | Запуск | Команда навыка | Особенность |
|---|---|---|---|
| Claude Code | `claude` | `/chebu-tutor --guide` | Нет |
| Codex | `codex` | `$chebu-tutor --guide` | Codex вызывает навыки через `$`, а не через `/` |
| Cursor | `cursor-agent` | `/chebu-tutor --guide` | Каталог клона должен быть доверенным |
| Devin | `devin` | `/chebu-tutor --guide` | Каталог клона должен быть доверенным |
| Grok Build | `grok` | `/chebu-tutor --guide` | Нет |
| OpenCode | `opencode` | `/chebu-tutor --guide` | В подсказке `/` навыка нет. Набери команду целиком: агент найдёт навык по строке [AGENTS.md](../AGENTS.md) |

Сам агент навык не вызывает: вызов идёт только от тебя. Запуск без интерфейса, например `claude -p`, описывает [runtime-adapters.md](chebu-tutor-docs/runtime-adapters.md).

## Примеры по ситуациям

| Ситуация | Команда | Что сделает агент |
|---|---|---|
| Первая сессия, режим уже выбран | `/chebu-tutor --walkthrough разберём agent_loop() в agent/chebu.py` | Сообщит о первой сессии, проверит Git и начнёт разбор после согласия на маршрут |
| Первая сессия, режим не выбран | `/chebu-tutor` | Напечатает строку использования, покажет таблицу режимов и спросит один раз |
| Продолжить шаг в том же режиме | `/chebu-tutor продолжить с шага из снимка` | Возьмёт режим из снимка, сверит снимок с Git и предложит одно следующее действие |
| Продолжить в другом режиме | `/chebu-tutor --quiz` | Подтвердит смену строкой `Режим тьютора: quiz по флагу, в снимке был guide` |
| Начать новый тикет и писать самому | `/chebu-tutor --guide начать тикет EDU-07, код пишу сам` | Прочитает файл тикета, воспроизведёт нынешнее поведение и согласует минимальный план |
| Агент делает тикет, ты смотришь | `/chebu-tutor --execute тикет EDU-06, объясняй каждый шаг и останавливайся после него` | Согласует план, меняет один участок за раз и показывает команду, вывод и diff |
| Проверить «а что будет, если» | `/chebu-tutor --sandbox покажи, что вернёт run_bash("exit 3")` | Создаст `.sandbox/<тема>/`, запустит пример на копии и объяснит, что пример доказывает |
| Повторить темы с ошибками | `/chebu-tutor --quiz повторить темы из раздела «Вернуться» снимка` | Задаст один вопрос по этим темам и подождёт ответа |
| Сменить режим посреди сессии | `/chebu-tutor --guide` в том же разговоре | Подтвердит смену строкой `Режим тьютора: guide по флагу, был walkthrough` |
| Продолжить в другом рантайме | «закрой сессию», затем команда из вывода `save`, например `codex '$chebu-tutor --guide'` | Продолжит тот же режим: снимок общий для шести рантаймов |

Тикеты лежат в [tickets/](../coding-agent-developement/tickets/README.md).

## Разрешения пишутся словами

Разрешения не переходят из прошлого снимка. Назови их после флага в той же команде:

```text
/chebu-tutor --execute тикет EDU-06. Коммит разрешаю, push и PR не делать. DeepSeek не запускать.
```

| Что разрешить или запретить | Что написать |
|---|---|
| Платный запуск `chebu` | `Разрешаю один запуск chebu с ключом DeepSeek.` или `DeepSeek не запускать.` |
| Коммит и публикацию | `Коммит разрешаю, push и PR не делать.` |
| Ветку для работы | `Работаем в ветке edu-06.` |
| Трекер на GitHub | `Разрешаю менять статус тикета в моём Project.` или `Issues и Project не трогать.` |

Локальные тесты из `agent/` разрешения не требуют: они подменяют API и ничего не стоят.

## Что ты увидишь в ответ

Первая строка ответа называет режим или причину отказа. Строки ниже печатает `handoff.py start --mode`, а последние две строки таблицы пишет сам агент.

| Ситуация | Сообщение | Что дальше |
|---|---|---|
| Флаг совпал с режимом снимка | `Режим тьютора: guide, из снимка и флага` | Сессия продолжается |
| Флаг отличается от режима снимка | `Режим тьютора: walkthrough по флагу, в снимке был execute` | Сессия идёт в режиме флага |
| Снимка нет или в нём нет режима | `Режим тьютора: walkthrough по флагу, в снимке режима нет` | Сессия идёт в режиме флага |
| Флага нет | `использование: chebu-tutor --execute\|--guide\|--walkthrough\|--sandbox\|--quiz [цель, тикет, ограничения]` | Режим берётся из снимка |
| Два флага | `ошибка: нужен один флаг режима, получено 2: --guide --quiz.` и строка использования | Работа не начинается |
| Флаг вне списка | `ошибка: флаг --exec не входит в список режимов.` и строка использования | Работа не начинается |
| Рантайм запущен вне клона | `навык chebu-tutor работает только в клоне chebupelka-jev` | Работа не начинается |
| Флаг в начатой сессии | `Режим тьютора: guide по флагу, был walkthrough` | Сессия продолжается в новом режиме |

После строки режима агент показывает:

1. Вывод команды `start`: рантайм, путь к снимку и время снимка.
2. Расхождения снимка с Git и с выбранным тикетом.
3. Одно следующее действие.

Работа начинается после твоего согласия с планом.

## Во время сессии

| Что нужно | Что написать |
|---|---|
| Сменить режим | `/chebu-tutor --quiz` или фразу «дальше пишу сам», «переключись в quiz» |
| Получить следующую подсказку в `guide` | «дай подсказку следующего уровня» |
| Разрешить платный запуск | «разрешаю один запуск chebu с ключом» |
| Проверить, что режим не тронул файлы | `git status --short` до шага и после него |
| Сохранить сессию | «закрой сессию» |

После «закрой сессию» агент сохраняет снимок командой `handoff.py save` и передаёт тебе её вывод. В нём по одной команде продолжения на рантайм, с режимом сохранённого снимка:

```text
Продолжить в любом рантайме из корня основного клона:
  claude "/chebu-tutor --guide"
  codex '$chebu-tutor --guide'
  cursor-agent "/chebu-tutor --guide"
  devin -- "/chebu-tutor --guide"
  grok "/chebu-tutor --guide"
  opencode --prompt "/chebu-tutor --guide"
Без навыка: «Продолжи работу по AGENTS.md и .handoff/SESSION.md.»
```

Запусти нужную команду в корне клона или набери `/chebu-tutor --guide` в открытом рантайме. Последняя строка нужна, если навыка нет.

> [!TIP]
> Закрывай сессию перед паузой и перед сменой рантайма. Изменения после последнего сохранения, например смена режима, в снимок не попадают.

> [!WARNING]
> Рантайм может показывать рассуждения модели. В режиме `quiz` не читай их до своего ответа: в них может появиться верный ответ.

## Если что-то пошло не так

| Что ты видишь | Причина | Что сделать |
|---|---|---|
| `ошибка: нужен один флаг режима, получено 2`, хотя флаг один | В цели есть слово на `--`, например `--runtime` | Напиши слово без дефисов: «разберём ключ runtime» |
| `ошибка: флаг --exec не входит в список режимов.` | Опечатка или сокращение флага | Напиши флаг полностью: `--execute` |
| `навык chebu-tutor работает только в клоне chebupelka-jev` | Рантайм запущен вне клона | Перейди в корень клона и запусти рантайм заново |
| Codex не знает `/chebu-tutor` | В Codex навык вызывается через `$` | Набери `$chebu-tutor --guide` |
| В подсказке `/` OpenCode навыка нет | OpenCode 2.0.32 не показывает этот навык в подсказке | Набери `/chebu-tutor --guide` целиком и отправь |
| Рантайм не знает команду в ветке тикета | Ветка начата от тега без навыка, например v0.1.4 | Проверь `ls .claude/skills/chebu-tutor`. Если папки нет, начни сессию [промптом](#без-навыка-промпт) |
| В ответе нет строки `Режим тьютора:` | Рантайм не приложил текст навыка к сообщению | Напиши: «выполни навык по .claude/skills/chebu-tutor/SKILL.md» |
| В строке `Режим тьютора:` другой режим, чем в твоём флаге, например `guide` вместо `execute` | Модель изменила слова вызова до команды проверки. Так было в Devin при проверке 0.1.1 | Напиши: «флаг был `--execute`, повтори команду проверки с ним» |
| Агент выполнил `start` без `--mode`, и в ответе нет `по флагу` или `из снимка и флага` | Модель пошла по шагу 1 «Начни сессию» AGENTS.md вместо команды проверки навыка. Так было в Devin с навыком 0.1.0, версия 0.1.1 это исправляет | Напиши: «выполни команду проверки из шага 2 навыка chebu-tutor» |
| Cursor или Devin отказываются работать в каталоге | Каталог не отмечен доверенным | Отметь каталог клона доверенным в рантайме |
| Codex в git worktree не сохраняет снимок: `PermissionError` | Песочница Codex не пускает запись в основной клон | Выполни `python3 .handoff/handoff.py save` из worktree в обычном терминале |

## Без навыка: промпт

Промпт нужен, когда навыка нет: облачная сессия, ветка от тега до `chebu-tutor-v0.1.0` или рантайм вне шести. Начни сессию фразой:

```text
Начни учебную сессию.
```

Полный промпт сразу называет цель, режим и ограничения:

```text
Продолжи работу по AGENTS.md и .handoff/SESSION.md.
Моя цель на эту сессию: <цель или «выбрать вместе»>.
Режим на эту сессию: <режим>.
Особые ограничения: <ограничения или «нет»>.
```

Агент начнёт сессию так же, по [AGENTS.md](../AGENTS.md), только без проверки флага кодом. Промпты для разных ситуаций собраны в разделе [«Без навыка: промпт»](../coding-agent-developement/tutor-modes.md#без-навыка-промпт) tutor-modes.md.

## Как устроен навык

Своих правил тьютора у навыка нет. Он проверяет флаг и передаёт сессию правилам проекта:

```text
/chebu-tutor --guide тикет EDU-02
        |
        v
корень Git с AGENTS.md и .handoff/handoff.py? -- нет --> «работает только в клоне»
        | да
        v
python3 .handoff/handoff.py start --runtime <id> --mode  <-- твои слова на stdin
        |
        +-- код 2: строка использования, работа не начинается
        |
        v
брифинг и строка «Режим тьютора:», затем начало сессии по AGENTS.md
        |
        v
раздел режима в tutor-modes.md, план, твоё согласие, работа
```

Твои слова идут в команду через heredoc с разделителем в кавычках, поэтому shell не выполняет `$`, кавычки и обратные кавычки из текста. Подробности описывают [контракт](chebu-tutor-docs/contract.md) и [архитектура](chebu-tutor-docs/architecture.md).

## Разработка навыка

Этот каталог хранит исходник навыка, генератор адаптеров, тесты и документацию. Изменения версий ведёт [CHANGELOG.md](CHANGELOG.md), правила номеров и выпуска описывает [versioning.md](chebu-tutor-docs/versioning.md). С пакета [chebu-tutor-docs](chebu-tutor-docs/README.md) начинается любая сессия разработки.

| Путь | Назначение |
|---|---|
| `skill.json` | Имя, версия и требования навыка |
| `source/SKILL.md` | Канонический текст навыка |
| `source/agents/openai.yaml` | Запрет вызова моделью для Codex |
| `tools/sync.py` | Генератор адаптеров и проверка синхронизации |
| `tests/` | Тесты навыка |
| `CHANGELOG.md` | История версий навыка |
| `chebu-tutor-docs/` | Контракт, архитектура, факты о рантаймах, этапы разработки |

Адаптеры лежат вне этого каталога: папка `.claude/skills/chebu-tutor/` и ссылка на неё `.agents/skills/chebu-tutor`. Их читают рантаймы, а пишет только `tools/sync.py`. Вручную адаптеры не правят. После правки `source/`, `skill.json` или блока `skill` в `runtime-config/runtimes/` запусти генератор и закоммить адаптеры вместе с источником. Из корня репозитория:

```bash
python3 chebu-tutor-skill/tools/sync.py
python3 chebu-tutor-skill/tools/sync.py --check
python3 -m unittest discover -s chebu-tutor-skill/tests -v
```
