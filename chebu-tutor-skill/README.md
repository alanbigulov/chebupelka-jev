# chebu-tutor-skill

Каталог для разработки навыка `chebu-tutor`: его кода, скриптов и документации. Навык будет вести учебную сессию в режиме, который ученик задаёт флагом команды, одинаково в шести рантаймах репозитория.

## Статус

Разработка не начата. В каталоге есть только пакет документации [chebu-tutor-docs](chebu-tutor-docs/README.md). Навык ещё нельзя вызвать: файлов `skill.json`, канонического текста, генератора и адаптеров нет. Статус этапов ведёт [progress.md](chebu-tutor-docs/progress.md).

## Что появится здесь

| Путь | Назначение | Этап |
|---|---|---|
| `chebu-tutor-docs/` | Документация и поэтапные инструкции разработки | Есть |
| `skill.json` | Имя, версия и требования навыка | 2 |
| `CHANGELOG.md` | История версий навыка | 2 |
| `tests/` | Тесты навыка | 2–4 |
| `source/SKILL.md` | Канонический текст навыка | 3 |
| `tools/sync.py` | Генератор адаптеров и проверка синхронизации | 4 |

Адаптеры будут лежать вне этого каталога, в `.claude/skills/chebu-tutor/` и `.agents/skills/chebu-tutor/`, которые читают рантаймы. Почему так, объясняет [architecture.md](chebu-tutor-docs/architecture.md).
