# Учебная работа над chebupelkajev

Эта папка хранит объяснения реализованного агента и план его дальнейшего развития. Название `coding-agent-developement` сохраняется по решению владельца проекта.

## Порядок изучения v0.1.0

| Урок | Что разберём | Практический результат |
|---|---|---|
| [01. Установка и история](lessons-v0.1.0/01-setup-and-history.md) | Git, upstream, merge, uv, Python, DeepSeek | Понимание воспроизводимой подготовки проекта |
| [02. Архитектура](lessons-v0.1.0/02-agent-architecture.md) | Компоненты, сообщения, инструменты и границы исполнения | Понимание полного цикла агента |
| [03. Разбор кода](lessons-v0.1.0/03-code-walkthrough.md) | Python-выражения и все этапы исполнения | Возможность проследить задачу через функции |

```text
Подготовка проекта
        |
        v
Архитектура и данные
        |
        v
Пошаговый разбор исходника
        |
        v
Roadmap → выбранная задача → проверка → новая версия и уроки
```

## Связь с кодовой базой

Исходник: [chebupelkajev.py](../chebupelkajev.py). Метаданные: [pyproject.toml](../pyproject.toml). Зависимости: [uv.lock](../uv.lock). Правила выпуска: [VERSIONING.md](../VERSIONING.md). Реализованные изменения: [CHANGELOG.md](../CHANGELOG.md).

Уроки в `lessons-v0.1.0` описывают именно выпуск `v0.1.0`. Относительные ссылки ведут к файлам в текущем checkout. [Код по неизменяемому тегу](https://github.com/alanbigulov/chebupelka-jev/blob/v0.1.0/chebupelkajev.py) позволяет сверяться с историческим состоянием после дальнейших изменений.

## Как продолжать обучение

1. Выбрать одну задачу из [development-roadmap.md](development-roadmap.md).
2. Разобрать нынешнее поведение и конкретный пример проблемы.
3. Согласовать минимальное изменение и наблюдаемый результат.
4. Реализовать и проверить его, записать результаты и перевести задачу в следующий статус.
5. При выпуске создать уроки соответствующей версии и обновить навигацию.

Статус `завершено` присваивается после проверки результата. Планируемые задачи не описываются как возможности текущего агента. Старые уроки сохраняют историческую реализацию; исправления фактических ошибок допустимы с пояснением.
