# История изменений chebupelkajev

Все существенные изменения самостоятельного учебного проекта фиксируются здесь. Правила номеров и выпуска описаны в [VERSIONING.md](VERSIONING.md).

## [Unreleased]

Изменения следующей версии пока не реализованы. План и критерии готовности ведутся в [development-roadmap.md](coding-agent-developement/development-roadmap.md).

## [0.1.2], 2026-10-08

Организационный учебный выпуск: текущее состояние репозитория, публичный трекер и подробный урок о его создании. Логика агента и два существующих теста сохранены.

### Трекинг и обучение

- Создан публичный GitHub Project «chebupelkajev — Разработка и обучение», связанный с репозиторием.
- Созданы 12 EDU issues и отдельные задачи урока и приёмки, всего 14 тикетов.
- Настроены три Kanban-представления, шесть Status-колонок, labels, milestones, Приоритет и Порядок; нужные поля видимы на карточках.
- GitHub стал основным трекером; учебный roadmap хранит смысл задач и ссылки на актуальные issues.
- Добавлены `lessons-v0.1.2/version.md` и подробный урок `01-github-project-tracking.md` с командами, пояснениями и ASCII-схемами.
- Добавлен публичный регламент `project-tracking.md`; навигация и журнал структуры обновлены.
- Настроена единая локальная передача между coding agents. В публичном уроке handoff описан только в общих чертах; `.handoff/`, шаблон, SESSION и архив остаются ignored.

### Уточнение состава выпуска

- По решению владельца v0.1.2 фиксирует организацию и обучение без реализации будущих исправлений.
- EDU-01, EDU-02, EDU-03 и незавершённая часть EDU-06 перенесены в предварительную v0.1.3 и остаются открытыми.
- Критерии #13/#14 уточнены под текущий урок и выпуск; закрытие выполняется после проверки и публикации с записью доказательств.
- Project и milestones являются живыми внешними ресурсами; Git-тег не замораживает их дальнейшее состояние.

### Ранее добавленные изменения, вошедшие в снимок

- README описывает исследовательский проект по разработке coding agents с помощью coding agents, участие Codex и происхождение от исходного проекта автора.
- Репозиторий переведён в публичный режим.
- Добавлена MIT-лицензия для собственных материалов, тестов и изменений с явным исключением заимствованных частей upstream.

### Версия и проверки

- Версия проекта и локального пакета в lock-файле согласована как `0.1.2`; версии зависимостей не менялись.
- Исходник и тесты сравнены с v0.1.1; проверены lock-файл, два существующих локальных сценария, ссылки и конфигурация GitHub.
- API-проверки отделены от визуального просмотра: браузер при настройке был недоступен. Платные запросы DeepSeek не выполнялись.
- Старые уроки и теги сохранены; выпуск закрепляется новым аннотированным тегом `v0.1.2`.

## [0.1.1], 2026-10-07

Структурный учебный выпуск. Логика агента побайтово сохранена относительно v0.1.0. По решению владельца выпуск получает номер v0.1.1, хотя путь и каталог запуска изменились.

### Разделение модулей

- Python-файл, `pyproject.toml`, `uv.lock` и `.python-version` перенесены из корня в `agent/`.
- Версия проекта и локального пакета в lock-файле обновлена до `0.1.1`; версии зависимостей сохранены.
- Создан README исполняемого модуля; корневой README стал обзором проекта и курса.
- Создано отдельное локальное окружение `agent/.venv`; прежнее корневое окружение оставлено для отката и не входит в Git.

### Снимки и обучение

- В учебный модуль добавлен `project-structure.md` с причинами решений, правилами размещения и журналом изменений.
- Пакеты уроков v0.1.0 и v0.1.1 получили `version.md` с привязкой к коду и командами восстановления.
- Ссылки старых уроков на исходник и конфигурацию закреплены за полным SHA v0.1.0; исторические команды сохранены.
- Добавлен урок v0.1.1 о разделении проекта, тегах, worktree и границах воспроизводимости.
- На учебной машине создан соседний worktree `chebupelkajev-v0.1.0` с отдельным окружением. Эта папка не является частью коммита и на другой машине создаётся вручную.

### Проверки

- Добавлены два теста на стандартном `unittest`: обычный текстовый ответ и один `pwd` с полным результатом и ID инструмента во втором запросе.
- Синтетические JSON fixtures созданы вручную; `requests.post` подменяется, облачные запросы не выполняются.
- Подготовлены оба окружения через `uv sync --locked --offline`; проверены одинаковые исходники и сохранность старого тега.
- EDU-06 отмечена частично выполненной. Проверки ошибок, нескольких инструментов и лимита ходов остаются будущими задачами.

### Изменение команд

Для v0.1.1 перейди в `agent/` перед `uv sync` и `uv run`. Для снимка v0.1.0 выполняй его исторические команды из корня старого worktree. Подробности в [VERSIONING.md](VERSIONING.md).

## [0.1.0], 2026-10-07

Первый выпуск самостоятельного учебного проекта на основе [chebupelka](https://github.com/alexey-goloburdin/chebupelka) Алексея Голобурдина.

### Подготовка и происхождение

- Исходная история добавлена через remote `upstream` и объединена с собственным репозиторием с помощью `--allow-unrelated-histories`.
- Конфликт двух независимо добавленных README разрешён сохранением документа автора на этапе установки.
- Создана `.venv` с Python 3.14.7 через Homebrew `uv` 0.12.14; зависимости установлены и проверены.
- Исправлено старое имя `agent-loop` в lock-файле, затем имя текущего проекта обновлено до `chebupelkajev`.

### Подключение модели

- Настроены `https://api.deepseek.com` и API-идентификатор модели `deepseek-flash`.
- Ключ читается из `DEEPSEEK_API_KEY`, вместо записи в исходники.
- В запрос добавлено `thinking: {"type": "disabled"}`, чтобы текущий цикл не требовал обработки `reasoning_content`.

### Самостоятельный проект и обучение

- `chebupelka.py` переименован в `chebupelkajev.py`; логика существующего агента сохранена.
- Имя проекта согласовано в `pyproject.toml` и `uv.lock`; версия зафиксирована как `0.1.0`.
- README заменён актуальными инструкциями самостоятельного проекта с сохранением ссылки на автора.
- Созданы три подробных урока в `coding-agent-developement/lessons-v0.1.0/`, навигация и трекер будущих улучшений.
- Добавлены правила версии и этот журнал. Оба файла имеют право исполнения `+x`, но содержат Markdown, а не программы.
- Выпуск фиксируется аннотированным Git-тегом `v0.1.0`.

### Проверенные сценарии и границы проверки

В обучающей сессии до переименования API вернул `HTTP 200` и ответ `Да`. Агент выполнил `pwd` одним вызовом инструмента и завершился после двух обращений к модели. Версии Python и `requests` проверены запуском в окружении проекта.

При подготовке выпуска Python-код побайтово сравнен с предыдущим коммитом. Проверены метаданные и lock-файл через `uv lock --check --offline`, реальная команда `pwd` через `call_tool()` и двухходовый цикл с подставными HTTP-ответами без сетевого запроса. Повторная проверка облачного сервиса в выпуск не входит. Известные ограничения обработки нескольких инструментов, ошибок HTTP и выполнения shell-команд остаются открытыми задачами roadmap.
