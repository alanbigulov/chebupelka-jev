# chebupelkajev

Учебный кодинговый агент на Python. Получает задачу из терминала, обращается к DeepSeek и выполняет запрошенные моделью команды через системную оболочку.

Проект основан на [chebupelka Алексея Голобурдина](https://github.com/alexey-goloburdin/chebupelka). Исходная история Git сохранена. Этот репозиторий развивается самостоятельно под именем `chebupelkajev`, чтобы изучать устройство агентов и последовательно улучшать их реализацию.

Текущая версия: **v0.1.0**. Учебные материалы: [начало курса](coding-agent-developement/README.md). Правила выпуска: [VERSIONING.md](VERSIONING.md). История версий: [CHANGELOG.md](CHANGELOG.md).

## Что подготовлено в v0.1.0

- История автора объединена с собственным репозиторием через `upstream`, без потери исходных коммитов.
- Создано окружение через `uv`. В учебной сессии проверены Python 3.14.7 и `requests` 2.34.2.
- Настроен DeepSeek: URL `https://api.deepseek.com`, модель `deepseek-flash`, режим рассуждений отключён.
- Ключ читается из `DEEPSEEK_API_KEY` и не записывается в исходники.
- Проверены отдельный API-запрос и полный цикл с одним вызовом `pwd`.
- Файл и метаданные проекта переименованы в `chebupelkajev`; поведение агента сохранено.
- Добавлены подробные уроки, архитектурный разбор и [план следующих улучшений](coding-agent-developement/development-roadmap.md).

## Быстрый старт

Нужны Git, современный [uv](https://docs.astral.sh/uv/), ключ DeepSeek и доступный баланс API. `.python-version` выбирает Python 3.14; формальный минимум в `pyproject.toml` составляет 3.10.

В новой пустой директории:

```bash
git clone https://github.com/alanbigulov/chebupelka-jev.git
cd chebupelka-jev
uv sync --locked
```

`uv` создаёт `.venv` и при необходимости загружает подходящий Python. Если в macOS установлены два экземпляра `uv`, как в нашей сессии, вместо `uv` используй `"$(brew --prefix)/bin/uv"`. Подробности в [уроке установки](coding-agent-developement/lessons-v0.1.0/01-setup-and-history.md).

Ввод ключа без отображения символов в **zsh**:

```zsh
read -rs "DEEPSEEK_API_KEY?Вставь ключ DeepSeek и нажми Enter: "
printf '\n'
export DEEPSEEK_API_KEY
```

Ключ действует в текущей сессии терминала. После открытия нового терминала введи его снова. Программа не читает `.env` автоматически.

```bash
uv run python chebupelkajev.py "Вызови инструмент bash ровно один раз с командой pwd. Затем сообщи текущую директорию и заверши работу. Файлы не изменяй."
```

> [!WARNING]
> Агент выполняет команды с правами пользователя, без подтверждения и изоляции. Формулировка задачи не является техническим ограничением команд. Используй отдельную учебную директорию. API-запросы платные; текущий предел составляет 1000 ходов.

## Архитектура

```text
Задача из терминала
        |
        v
agent_loop() ---> call_llm() ---> DeepSeek
     ^                              |
     |               +--------------+---------------+
     |               |                              |
     |          tool_calls                     обычный ответ
     |               |                              |
     |          call_tool()                       завершение
     |               |
     |           run_bash()
     |               |
     +--- история <--+--- результат системной команды
```

Вся реализация находится в [chebupelkajev.py](chebupelkajev.py). Модель выбирает действие, Python выполняет его и отправляет результат обратно. Единственная прямая внешняя зависимость: `requests`; SDK и агентные фреймворки не используются.

| Функция | Ответственность |
|---|---|
| `agent_loop()` | История сообщений, обработка вызовов и условие завершения |
| `call_llm()` | HTTP-запрос и извлечение текста и инструментов |
| `call_tool()` | Выбор функции по имени и распаковка аргументов |
| `run_bash()` | Системная команда, её вывод и код завершения |

## Настройки и ограничения

| Настройка | Значение v0.1.0 |
|---|---|
| `LLM_BASE_URL` | `https://api.deepseek.com` |
| `LLM_MODEL` | `deepseek-flash`, API-имя выбранной в сессии DeepSeek-V4.1-Flash |
| `LLM_API_KEY` | `os.environ["DEEPSEEK_API_KEY"]` |
| `thinking.type` | `disabled` |
| `MAX_TURNS` | 1000 |
| Таймаут команды | 120 секунд |

Имя `bash` не фиксирует оболочку Bash: `subprocess.run(..., shell=True)` использует системную оболочку. HTTP-таймаут не задан. История хранится в памяти одного запуска. Одновременные вызовы нескольких инструментов требуют доработки; проверенный сценарий содержит один вызов. Эти задачи отслеживаются в [roadmap](coding-agent-developement/development-roadmap.md).
